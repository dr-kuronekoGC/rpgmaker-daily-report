# RPG Maker Daily Report

RPG Maker関連のプラグイン・素材・開発情報などを自動収集し、Slackに通知するプロジェクトです。

## 目的

RPG Makerに関する情報を継続的に集め、見落としを減らすとともに、将来的に検索・活用できる情報データベースを整備することを目指しています。

## 主な機能

- **情報収集**：公式サイト、コミュニティ、フォーラム、素材配布サイトなどから情報を収集
- **重複チェック**：同じ情報の繰り返し通知を防止
- **分類・整理**：プラグイン、素材、開発情報などに分類
- **Slack通知**：新着情報や確認が必要な情報を通知
- **PRE管理**：判断が必要な情報を記録し、確認状況を管理
- **Notion連携**：PRE確認台帳とGitHubの情報を同期

## 仕組み

GitHub Actionsで定期的に収集処理を実行し、収集した情報を整理・保存したうえでSlackに通知します。

確認が必要な情報はPREとして管理し、最終的な採用・公開の判断は人が行います。

## 使用技術

- Python
- GitHub Actions
- Slack Incoming Webhook
- Notion API
- JSONによるデータ管理

## 関連プロジェクト

収集した情報を検索・閲覧できるWebサイト「[黒ネコの酒場](https://github.com/dr-kuronekoGC/kuroneko-tavern)」を別リポジトリで開発しています。

## 運用方針

情報収集は自動化しますが、情報の正確性や公開の可否は人が確認します。配布元へのリンクを尊重し、無断転載は行いません。
